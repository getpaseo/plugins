# Tom Gringauz plugin icons

Directory icons for the `tomgrin10/*` plugins. The registry uses the PNGs through `listing.icon`; no plugin artifact or install pin changes.

Each 256 × 256 PNG is rendered from its adjacent SVG, using the same slate tile, warm white stroke, padding, and 1.8-unit Lucide stroke. The tile keeps the glyph visible on light and dark directory backgrounds.
