Redraws the chat stream with themed, syntax-highlighted cards for tool calls, reasoning, prompts, replies, approvals, checklists, and errors. It is built around Oh My Pi (OMP) tool output and applies to agent chats including OMP. It requires Paseo 0.8.0 or newer.

Settings under Plugins, Beautiful Chat cover accent color, fonts, frosted glass, the prompt bubble, and assistant markdown. Turning off the enhanced prompt bubble hands prompts back to Paseo, which is needed to show pasted images, and turning off assistant markdown hands replies back to Paseo's renderer. Preference changes apply to new items, and items already on screen need a reload. On desktop and web the plugin also adds its own Ctrl/Cmd+F find bar over the chat, which searches only messages already loaded, and a Copy and Add to chat bar for selected text. Those two and the pointer glow do not apply on iOS and Android.

Three actions run on the daemon host. Syntax highlighting is computed there. Image reads show a thumbnail of an image file (PNG, JPEG, GIF, WebP, AVIF, BMP, ICO, SVG, up to 3 MB) from the agent's working directory or an absolute path. File names in cards are links that ask the daemon to reveal the path in the platform's file manager. Remote image URLs that a model writes into a reply are rendered as images, and links open through the platform opener only when clicked. Preferences are stored in the client's local storage.
