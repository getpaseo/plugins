This plugin adds two themes to Paseo, ported from an Obsidian theme: Everforest Enchanted (dark) and Everforest Enchanted Light (light). Select either under Settings → Appearance → Theme. It changes Paseo's colors only and has no settings. It requires Paseo 0.8.0 or later.
