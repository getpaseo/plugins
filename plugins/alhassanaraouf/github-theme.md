This plugin adds two themes to Paseo, ported from an Obsidian theme: GitHub Theme (dark) and GitHub Theme Light (light). Select either under Settings → Appearance → Theme. It changes Paseo's colors only and has no settings. It requires Paseo 0.8.0 or later.
