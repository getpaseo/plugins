Vicious is a color theme for Paseo with a dark variant (near-black blue background, off-white text) and a light variant (off-white background, near-black text), both with a pale gold accent. It only changes colors (background, text, raised surfaces, controls, borders, accent, muted text and focus ring). Requires Paseo 0.8.0 or newer. Select **Vicious** or **Vicious Light** under Settings, Appearance, Theme.
