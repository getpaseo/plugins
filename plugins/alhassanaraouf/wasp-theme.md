Wasp is a color theme for Paseo with a dark variant (charcoal background, cream text, yellow accent) and a light variant (warm off-white background, dark brown text, amber accent). It only changes colors (background, text, raised surfaces, controls, borders, accent, muted text and focus ring). Requires Paseo 0.8.0 or newer. Select **Wasp** or **Wasp Light** under Settings, Appearance, Theme.
