Willemstad is a color theme for Paseo with a dark variant (near-black background, white text, violet accent) and a light variant (white background, black text, lighter violet accent). It only changes colors (background, text, raised surfaces, controls, borders, accent, muted text and focus ring). Requires Paseo 0.8.0 or newer. Select **Willemstad** or **Willemstad Light** under Settings, Appearance, Theme.
