Create a project team in Paseo, with one workspace, provider and model for each role and an orchestrator to delegate your requests. Open the Agent team workspace panel or run Create agent team from the Command Center. The sidebar also offers team creation for projects without a team.

Requires Paseo 0.13.0 or newer and at least one ready provider on the host. Describe your goal to have a planner propose roles, or start with an empty team. Review the workspace names, models, folders and instructions before pressing Apply.

Apply writes `.agents/team.json` in the registered project root, reuses project workspaces with matching titles or creates missing ones, and starts an orchestrator. Applying again reuses an orchestrator with the same provider and model when found. It then archives the project's plugin-labelled planner agents and unused, otherwise empty Team planner workspaces. Team definitions can be committed to your repository and edited in the panel or file.

The plugin reads project, workspace, agent and provider metadata and the team file. Planning sends your goal and available model IDs to the selected provider, preferring Claude when ready; the planner is instructed to inspect the repository. Orchestrator and role agents send their instructions, prompts and any repository content or tool results they read to their configured providers under those providers' normal behavior. These agents consume provider usage. The plugin has no separate external service or software download.

Role workspaces share the same project checkout. Folder assignments guide agents; they do not enforce filesystem isolation. Avoid overlapping work or ask the orchestrator to sequence it. The planner uses its provider's default mode and is instructed not to change files, but is not technically prevented from doing so. Large workspace and agent lists are read as a single page, so existing resources beyond that page can be missed. English and Korean UI text are included.
