Tidy Timeline folds noisy conversation rows into compact cards. The cards that unwrap injected skill text, inbox messages and system notices target omp, and they depend on omp's row formats. Long pasted user messages fold for every provider. The author's repository marks this version as archived, with development moved to a different repository.

The plugin runs only in the app. It has nothing on the daemon and stores nothing.

## Limit

Paseo 0.8 streams assistant messages in separate blocks, so an injected row can reach the plugin in pieces while it streams. A card can then show only its header until you reload the agent, which refetches whole rows.

Requires Paseo 0.8.0-beta.1 or later.
