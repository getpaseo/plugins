Better Diff gives you a diff and staging view for a workspace’s Git worktree. Read changes side by side or inline, search across files, and stage, unstage or discard files, hunks or selected lines. Discarding edits changes files on disk and can permanently lose uncommitted changes.

Leave comments on changed lines while you review. Paseo saves pending comments on the workspace. When you send a review, your comments, message and nearby diff lines go to the selected agent and its provider.

The plugin runs Git on the workspace host. Staging changes the Git index. Adding an ignore rule writes to the ignore file you select. The plugin makes no direct network requests.

Requires Paseo 0.16 or later and Git on the workspace host. The view is for desktop use. It does not resolve merge conflicts or submit GitHub pull request reviews.
