Mono adds two neutral gray themes, Mono Dark and Mono Light, selected under Settings, Appearance, Theme. It also adds interface tweaks that work with any theme and are all on by default, each of which you can turn off under Settings, Plugins, mono: compact sidebar navigation, fewer divider lines and outlines, hidden Thinking rows, simpler file attachments in the composer, and hidden dictation and voice mode buttons. These settings are stored on the host, so every client of that host shares them. The sidebar, divider and attachment tweaks apply on desktop and web, and the Thinking rows are hidden on every platform. On desktop and web, each model under Settings, Providers also gets a switch that hides it from the composer model picker and the new-agent model list, and the choice is saved to the host through Paseo. The selected model and agent profiles are not affected. The manifest requires Paseo 0.9.0 or later.
