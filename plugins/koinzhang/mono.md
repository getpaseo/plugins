Mono adds two neutral gray themes, Mono Dark and Mono Light, selected under Settings, Appearance, Theme. It also ships interface tweaks that work with any theme and are all on by default. Under Settings, Plugins, mono, you can turn each off individually: compact sidebar navigation, hiding dividers and borders, hiding Thinking rows, improved composer file attachments, hiding the dictation button, and hiding the voice mode button. The settings are stored per host, so every client of the same host shares them. On desktop and web, the sidebar tweak turns the top navigation (New workspace, History, Search, Schedules and plugin items) into one icon-only row, the border tweak removes divider lines and composer outlines, and the attachment tweak shows a file-type mark and filename with the path on hover. Thinking rows are hidden on every platform, and tool calls and messages are unchanged. On desktop and web, each model under Settings, Providers gets a switch that hides it from the composer model picker and the new-agent model list. These visibility choices are saved to the host's settings through Paseo, and the selected model and agent profiles are not affected. The manifest requires Paseo 0.9.0 or later.
