Adds Feishu-inspired light and dark themes with Chinese labels, selectable under Settings, Appearance. On native iOS and Android the themes change colors only. On desktop and in a browser a Feishu theme also restyles the layout, chat bubbles, and tool cards, and shows the first line of the reasoning text a provider exposes, with a copy button that writes to the clipboard only when pressed. That restyling adjusts Paseo's page structure, so it supports only Paseo 0.8.x and 0.9.x, on both the app and the daemon, and should be rechecked after an upgrade. Windows and Linux desktop are untested. The plugin is client-only, with no daemon component and no direct network access.
