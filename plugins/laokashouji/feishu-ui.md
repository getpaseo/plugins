Adds Feishu-inspired light and dark themes to Paseo (it is an independent project with no Feishu or Lark connection), selectable under Settings, Appearance, and the UI labels are in Chinese. On every client the themes change colors only. On macOS desktop and in a browser, while a Feishu theme is selected, a skin also restyles the layout, chat bubbles, and tool cards, and shows the first line of the reasoning text the provider exposes with a copy button that writes to the clipboard only when pressed. That skin works by adjusting Paseo's page structure, so it depends on the Paseo version and should be checked after an upgrade. It requires Paseo 0.8.x or 0.9.x on both the app and the daemon, and Windows and Linux desktop are untested. The plugin is client-only, with no daemon component or direct network access.
