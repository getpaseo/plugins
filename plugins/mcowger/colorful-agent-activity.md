Replaces Paseo's reasoning and tool-call rows with denser, color-coded activity rows on desktop, web, and mobile, with specialized views for Paseo's own tools and for Exa and GitHub results. It requires Paseo 0.9.0 or newer, and Paseo's Tool call detail setting must be Detailed, because Overview mode groups tool calls before plugins can see them. Internal orchestrator calls are left unchanged. Settings choose a color palette and how much detail stays expanded.

Inline image thumbnails come from a daemon request that reads the image file from the agent's working directory or an absolute path and checks that it is an image.
