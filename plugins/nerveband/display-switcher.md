Switches the sidebar grouping between Project and Status from keyboard shortcuts and the Command Center, and works on desktop and web. It requires Paseo 0.8.0 or newer.

Paseo has no API for changing the grouping, so the plugin operates the sidebar's Display menu through the page and checks the result against Paseo's saved sidebar setting in local storage. You record or clear the shortcut for each action from the Display Switcher sidebar screen, where shortcut capture can also be turned off, and the shortcuts are stored in local storage. While capture is on, the plugin listens for key presses across the whole page.
