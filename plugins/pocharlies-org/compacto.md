Compact view lets Paseo group consecutive tool calls into one expandable summary by hiding completed Thinking rows from the timeline. Reasoning remains visible while it streams, but its completed text is no longer shown in the chat history while this plugin is active.

In Settings → Chat, set **Tool call display** to **Summary** on each device. Requires Paseo >=0.11.2 and <0.12.0. The plugin only transforms timeline display and does not make independent network requests, read credentials or run commands.
