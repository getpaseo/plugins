Discord Rich Presence shows what you are working on in Paseo as your Discord activity: the project and workspace you used most recently, how many workspaces the project has, and whether agents are running, waiting for you or failed. The Paseo daemon and the Discord desktop app must run on the same machine.

The presence is on by default at the Detailed level, so project and workspace names appear on your Discord profile as soon as the plugin runs. Workspace titles can be generated by an agent and can contain task details. Before you leave it running, choose a level in the **Discord** screen: a global level of Detailed, Projects only (workspace names hidden) or Hidden (the presence reads only `Using Paseo`), a different level for each project, or switch the presence off, which clears it from Discord. A project set to Hidden is never named.

The plugin opens its own connection to the Paseo daemon to read workspaces, active agents and projects, and it needs Paseo 0.9.0 or newer. It cannot connect to a daemon that listens only on a Unix socket or named pipe, and the settings screen then reports that it cannot read Paseo. It sends the activity to the local Discord app, and the Discord app publishes it. Settings, including the project paths and names of per-project levels, are saved as Paseo plugin settings on the daemon host.
