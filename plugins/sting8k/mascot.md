Shows an animated mascot on the Paseo composer, in the web and desktop apps only. You pick a character from a catalogue, and the selection, name, and position are saved as one host-wide setting, so every composer on that host shows the same mascot. Existing composers get it automatically when the plugin loads, on a best-effort basis. If one is missing, or for an agent created later, run **Mascot: add a mascot to this composer** from Command Center.

The character images are requested from `koboyo.com`, images only, no code. To animate, the mascot reads cursor movement and the position and size of the text field you are typing in, not the keys or the text, plus the status of the workspace.
