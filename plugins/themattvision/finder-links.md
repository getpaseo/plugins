Finder Links makes local file links in assistant messages open in your system file manager. Clicking a link to a file selects it in Finder on macOS or File Explorer on Windows. For a directory, macOS reveals it in Finder and Windows opens it in File Explorer. It works only in Paseo's web-based clients, including the desktop app, and not in native mobile clients. Linux is not supported.

The plugin intercepts only plain primary clicks on local-file links in assistant messages. Web links, modified clicks, and source references such as `src/app.ts:42` keep Paseo's built-in behavior. A `~/` path resolves against the home directory of the user running the daemon. A relative path resolves against the working directory of the active agent, or against the workspace when no agent is involved. File URLs, including Windows drive paths and UNC shares, are accepted.

The reveal runs on the machine where the daemon runs, so the file manager opens on that machine and not on the device you are clicking from. The plugin checks that the path exists, then asks Finder or File Explorer to reveal it, without going through a shell. It reads file metadata for the clicked path and does not read file contents. If the path is missing or the platform is unsupported, nothing is revealed, and the failure is only logged in the web client's console. The plugin requires Paseo 0.9.2 or later and has no settings.
