Transcript Search finds text in active and archived Paseo conversations across connected hosts, including Claude subagents and archived Codex sessions. Open it from the sidebar or Command Center, search, and filter by project, provider, labels, date, or archive status. Matching sessions open on their original host; restoring an archived session asks for confirmation.

Requires Paseo 0.14.0 or newer on the daemon and connected app. Each searchable host needs the plugin with the same installation ID. Queries use your app's existing authenticated Paseo connections and run on online hosts in parallel. The screen names disconnected hosts, missing plugins, failures, and incomplete results while retaining results from healthy hosts. Plugin settings can hide the sidebar entry without removing keyboard access.

Literal, case-insensitive search is the default; regular expressions, case sensitivity, and relevance ranking are optional. Searches cover selected sessions in bounded batches. Literal and regex searches use the host's `grep`, so Windows needs a compatible copy, such as Git for Windows. Ranked search uses a local SQLite FTS5 index and falls back to grep when unavailable.

The plugin reads Paseo session records under `$PASEO_HOME` and provider transcripts in their configured directories. Transcripts stay on their originating hosts; matching snippets and session metadata return to connected clients. Provider persistence credentials are excluded from history responses. Each host owns its search index, and results keep chronological grouping when hosts use different search engines. The screenshots use synthetic sessions on two hosts.

The composer **+** menu adds an **Attach Past conversation** source: it searches this host's sessions and sends the chosen title, workspace, matching turns (or how it started and its last turns) with your next message to the agent and its model provider.

Interactive Claude and Codex sessions also receive two tools on their own host: one searches conversations (the calling workspace by default; an agent can explicitly choose the current project or the whole host) and one reads the turns around a returned line of a session on that host, by agent ID. Both return bounded transcript text to the calling agent and its model provider, so broader scopes expose other conversations on that host to the provider. Neither restores, starts or messages agents. The session label `plugin-tools/enabled: "false"` disables the tools.
