Transfer, formerly Sync, copies or moves a workspace between hosts with its Git history, staged and unstaged changes, untracked files, and saved Claude or Codex conversations. Press **Transfer** at the top right of a workspace to open a popup with that workspace selected, choose a receiving host and a new directory, and review the preview before starting. The sidebar is hidden by default; enable it in plugin settings or use Command Center for the full screen and incoming transfers.

Both hosts need Paseo 0.11.0 or newer, Node 22 or newer, Git, and Linux, macOS, or WSL. The receiving host needs a running Paseo daemon, SSH access, and its own provider CLIs and credentials. Only the initiating host needs this plugin. Hosts can be selected from SSH aliases or online Tailscale peers, or entered manually; trust a new SSH host key before use. Stop running agents before transferring.

Transfers use SSH and existing Paseo authentication. Provider credentials, MCP settings, launch settings, and Git-ignored files stay on their original hosts. The plugin writes a new destination checkout and imports supported conversations, then verifies the destination. **Copy** keeps the source; **Move** archives it through Paseo only after verification, which can remove a managed source worktree. Move refuses worktrees containing ignored files.

Copies are independent checkouts. Occupied destinations, changed previews, unsafe paths, unsupported conversations, and submodules are refused; transfers are limited to 128 MiB and 20,000 files. Closing the popup does not stop a transfer. Registered partial transfers are kept for recovery after failure. Existing Sync installations retain the `sync` ID; new installations use `transfer`. The screenshot uses fixture workspace and host data.
