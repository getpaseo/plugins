Vitals shows how the machine running the Paseo daemon is doing and who is using it. CPU, RAM and disk meters sit at the bottom of the sidebar, and a Host vitals page splits the RAM in use between your agents, the Paseo daemon and plugins, Docker and everything else. Each agent row opens a panel with that agent's process tree, with memory and CPU per process. When RAM or disk passes 90%, a warning pill appears on every open agent's composer and names what is using the most RAM.

Per-process and per-agent figures need a Linux host. On macOS and Windows hosts you get host totals only, and the page says so. Docker figures are optional: if the `docker` command is available to the daemon's user, the plugin runs `docker stats` and `docker ps` and lists every container on the host, not only those Paseo started. Without Docker access the containers section reports it and the rest of the page is unaffected.

The plugin only reads. It never stops or changes a process or container, and it makes no network requests. It reads `/proc` and, from each Paseo-related process, only the `PASEO_AGENT_ID` value in its environment plus the process name, to attribute usage to agents. Command lines and other environment values are not read into the page. Anyone who can open the page sees the host name and the names of the largest processes on the machine. Display preferences are saved through Paseo plugin settings, where the sidebar row, footer meters and composer warning can each be turned off.

Interactive Claude and Codex sessions can also request the same host snapshot through a `vitals_host_snapshot` agent tool, including host identity, agent titles and Docker container names and health. These results reach the calling agent and its model provider; process environments and command lines are excluded. Set the session label `plugin-tools/enabled: "false"` to withhold the tool. Requires Paseo 0.14.0 or newer.
