通过聊天输入框旁的 **IDs** 按钮查看并复制当前 Agent 的 Paseo 会话 ID 与底层 CLI 会话 ID。弹出面板还会为识别的提供商生成恢复命令，包括 Claude、Codex、Antigravity、Pi、Hermes、OMP 和 OpenCode。命令仅复制到剪贴板，插件不会执行命令。

需要 Paseo 0.13.0 或更新版本，无需额外账户、令牌或工具配置。使用 `/ids` 或命令中心的“复制当前会话 ID”操作，可一起复制两个 ID、提供商及可用的恢复命令。

插件通过 Paseo 读取 Agent 会话元数据并订阅更新。较长的 ID 在面板中以掩码显示，复制时使用完整值。提供商尚未提供会话元数据时，CLI ID 不可用。插件没有独立的网络连接、服务端组件或文件系统访问。恢复命令取决于提供商及其报告的会话标识。
